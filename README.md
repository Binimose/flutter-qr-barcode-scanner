# flutter-qr-barcode-scanner

High-speed camera QR and Barcode scanner widget with custom viewfinder overlay.

`#flutter` `#qr-code` `#barcode-scanner` `#camera` `#utilities`

## Highlights
- Modular, clean architecture
- Documented API and straightforward integration
- Tested for performance and stability

## Quick Overview
```
// QR overlay border coordinates
class ScannerOverlayConfig {
  final double cutoutSize;
  final double borderRadius;
  ScannerOverlayConfig({this.cutoutSize = 250.0, this.borderRadius = 16.0});
}

```
